# Data dictionary

All files are in `data/processed/` and are generated by `python -m hippocrates run`.

## cleaned_clinical_trials.csv

One row per trial.

| Column | Meaning |
|---|---|
| `nct_id` | ClinicalTrials.gov identifier |
| `title` | Study title |
| `status` | Overall recruitment status |
| `conditions` | Listed conditions, lowercase, separated by `\|` |
| `interventions` | Listed interventions, separated by `\|` |
| `age_criteria` | Age categories such as `ADULT, OLDER_ADULT` |
| `locations` | Sites as `Facility, City, State, ZIP, Country`, separated by `\|` |
| `eligibility_text` | Lowercase brief summary. The name is kept for Power BI; it does not hold eligibility criteria. |
| `study_url`, `sex`, `phases`, `study_type`, `enrollment`, `sponsor`, `last_update` | Copied from the source |
| `eligibility_criteria`, `minimum_age`, `maximum_age` | Filled only by `fetch` |
| `age_min`, `age_max` | Exact limits when fetched, otherwise derived from the age categories |
| `text_age_min`, `text_age_max` | Age limits stated in the summary |
| `disease_setting` | `recurrent`, `newly_diagnosed` or `any` |
| `egfr_rule` | `required`, `targeted` (uses an EGFR drug, no stated selection) or `none` |
| `idh_rule` | `mutant`, `wildtype` or `any` |
| `mgmt_rule` | `methylated`, `unmethylated` or `any` |

## patient_diagnostics_mock.csv

One row per synthetic patient.

| Column | Meaning |
|---|---|
| `Patient_ID` | Synthetic identifier |
| `AI_Predicted_Condition` | Randomly generated diagnosis. No model produced it. |
| `Biomarker_EGFR` | `Positive`, `Negative` or `Not Tested` |
| `Biomarker_IDH` | `Mutant`, `Wildtype` or `Not Tested`, following the WHO 2021 definitions |
| `Biomarker_MGMT` | `Methylated`, `Unmethylated` or `Not Tested` |
| `Tumor_Volume_mm3` | Displayed only; not used in matching |
| `Patient_Age`, `Patient_Sex`, `Patient_Location` | Demographics |
| `Disease_Setting` | `Newly Diagnosed` or `Recurrent` |

## successful_matches.csv

One row per patient and candidate trial, best first within each patient.

| Column | Meaning |
|---|---|
| `Patient_ID`, `AI_Predicted_Condition`, `Patient_Age` | From the patient |
| `nct_id`, `trial_title`, `status`, `phases`, `study_type`, `sponsor`, `study_url` | From the trial |
| `match_score` | 0 to 100 |
| `match_tier` | `Strong`, `Good` or `Possible` |
| `patient_rank` | 1 is the patient's best match |
| `condition_match` | `exact` or `broad` |
| `geography` | Closest site: `city`, `state`, `country` or `unknown` |
| `best_site` | Label of that site |
| `sites_in_country` | Number of sites in the patient's country |
| `match_reasons` | Why it ranks here, separated by `; ` |
| `review_flags` | What a reviewer should check, separated by `; ` |

## match_funnel.csv

One row per patient. `trials_screened` is the starting count. For each gate, `excluded_<gate>` counts trials it removed and `remaining_after_<gate>` counts trials left. Gates are `condition`, `status`, `age`, `sex`, `biomarker`, `setting` and `geography`.
